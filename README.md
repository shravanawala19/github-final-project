# Simple Interest Calculator

A simple bash script designed to calculate simple interest based on the principal amount, annual rate of interest, and time period in years.

## Features
- Interactive user prompt for principal, annual interest rate, and duration.
- Calculates total interest and final amount.
- Lightweight and portable Bash script.

## Input & Output
- **Input:** Principal amount, Rate of interest per year, Time period in years.
- **Output:** Simple Interest = `(P * T * R) / 100`
